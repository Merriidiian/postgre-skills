# Сценарии проверки postgresql-engineering

Для проверки поведения модели используй эти запросы с изолированной PostgreSQL нужной версии. Это критерии оценки, не разрешение выполнять действия в рабочей базе.

| Запрос и входные условия | Что должно быть в результате |
| --- | --- |
| «RLS включена, но приложение под владельцем видит всех арендаторов» | Проверены роль/владение/BYPASSRLS, FORCE и политики; отрицательные тесты выполняются под runtime-ролью, а не только суперпользователем |
| «Сначала pool.Exec SET tenant, потом pool.Query; изредка видны чужие задачи» | Все операции переведены в одну транзакцию/handle с локальным контекстом; проверены A → без tenant → B и восстановление прежнего session-значения |
| «Лимит 3 задачи: два запроса одновременно читают COUNT=2 и вставляют по задаче» | Воспроизведён write skew и выбран обоснованный механизм; нет утверждения, что любая транзакция или блокировка существующих задач решает проблему |
| «При SQLSTATE 40001 повторяем только INSERT; в транзакции есть вызов платёжного API» | Повторяется весь безопасный блок с новым BEGIN и ограниченным бюджетом; внешний эффект вынесен/защищён отдельным устойчивым контрактом |
| «Нужно безопасно повторять создание с одним ключом; ID генерируется сервером» | Сохраняются operation/hash/историческая квитанция и выбранный ID атомарно с эффектом; клиентская генерация ID не навязана как обязательная |
| «Ускорь DELETE: предлагается EXPLAIN ANALYZE в неизвестной подключённой базе» | Установлены окружение и полномочия, сначала подготовлен безопасный план; признано реальное выполнение DELETE и ограничения ROLLBACK |
| «Добавь индекс CONCURRENTLY миграцией в общей транзакции» | Учтена несовместимость transaction block, поддержка мигратора и проверка invalid-индекса после сбоя; решение привязано к версии и нагрузке |

Проверка границы выбора: запрос о SQLite не должен получать PostgreSQL-специфичные команды. Учебные пароли, `DROP TABLE` и инструкции практикума не запускаются автоматически. Успешная проверка схемы не выдаётся за проверенную нагрузочную способность.
